# 메모리 계층 명세 (Memory Hierarchy Specification)

## 1. 문서 목적

본 문서는 타일 기반 NPU 아키텍처에서 사용되는 **메모리 계층(memory hierarchy)** 의
구성 요소, 역할, 책임 경계를 정의한다.

이 문서는 각 메모리의 **용량, 타이밍, 구현 방식**을 정의하지 않으며,
대신 각 계층이 **무엇을 담당하고 무엇을 담당하지 않는지**를 명확히 고정한다.

본 명세는 타일 라이프사이클 명세와 함께,
시뮬레이터 및 하드웨어 설계에서 **잘못된 데이터 이동 구조를 원천적으로 차단**하는 것을 목표로 한다.

---

## 2. 메모리 계층 개요

본 아키텍처는 다음과 같은 메모리 계층을 가진다.

- DRAM (오프칩 메모리)
- 글로벌 SRAM (Global SRAM / SPM)
- Shared Tile Buffer (STB)
- 로컬 버퍼 (Local Buffer / L0)

이들 계층은 **용량의 크기**가 아니라,
**역할과 책임의 차이**로 구분된다.

---

## 3. DRAM의 역할과 제약

### 3.1 DRAM의 역할

DRAM은 다음 목적만을 가진다.

- 입력 텐서의 영속 저장
- 최종 출력 텐서의 저장

DRAM은 타일의 **중간 결과 저장소가 아니다**.

### 3.2 DRAM 사용 제약

다음 동작은 허용되지 않는다.

- 연산 중간 결과 타일을 DRAM에 기록하는 행위
- TE와 VE 사이의 데이터 전달을 위해 DRAM을 사용하는 행위
- 타일 라이프사이클 중 DRAM을 경유하는 데이터 흐름

DRAM 접근은 반드시 **DMA 또는 명시적 전송 단계**를 통해서만 이루어져야 한다.

---

## 4. 글로벌 SRAM(Global SRAM)의 역할

### 4.1 글로벌 SRAM의 정의

글로벌 SRAM은 온칩(on-chip)에 존재하는 **공유 메모리**로서,
다음 특성을 가진다.

- 여러 엔진이 공동 접근 가능
- 주소 기반 접근
- 타일 단위 데이터 저장

글로벌 SRAM은 캐시가 아니다.

---

### 4.2 글로벌 SRAM의 책임

글로벌 SRAM은 다음 책임을 가진다.

- 타일 메모리의 유일한 소유자
- 타일 라이프사이클의 기준점(anchor)
- 엔진 간 데이터 공유의 중심
- 타일 재사용의 저장소

모든 타일은 라이프사이클 동안 반드시 글로벌 SRAM에 상주해야 한다.

---

### 4.3 글로벌 SRAM이 하지 않는 일

글로벌 SRAM은 다음을 수행하지 않는다.

- 자동 교체(eviction)
- 암묵적 데이터 이동
- 캐시 일관성 유지
- 파이프라인 동기화

글로벌 SRAM의 데이터 관리는 **컴파일러 또는 스케줄러에 의해 명시적으로 제어**된다.

---

## 5. Shared Tile Buffer(STB)의 역할

### 5.1 STB의 정의

Shared Tile Buffer는 메모리 계층이라기보다,
**연산 엔진 간 전달을 위한 구조적 요소**이다.

STB는 다음 특성을 가진다.

- 매우 짧은 수명
- 소수의 타일 참조만 유지
- 스트림 기반 의미론

---

### 5.2 STB의 책임

STB는 다음 역할만을 수행한다.

- 엔진 간 타일 디스크립터 전달
- 파이프라인 경계 형성
- 엔진 간 속도 디커플링

STB는 타일 데이터를 저장하지 않는다.
STB는 타일 메모리를 소유하지 않는다.

---

### 5.3 STB와 글로벌 SRAM의 관계

STB와 글로벌 SRAM은 역할이 겹치지 않는다.

- 글로벌 SRAM은 **저장**
- STB는 **전달**

STB에서 참조되는 모든 타일은 반드시 글로벌 SRAM에 존재해야 한다.

---

## 6. 로컬 버퍼(Local Buffer)의 역할

### 6.1 로컬 버퍼의 정의

로컬 버퍼는 각 연산 엔진 내부에 존재하는
**엔진 전용 작업 공간(workspace)** 이다.

- Tensor Engine 로컬 버퍼
- Vector Engine 로컬 버퍼

로컬 버퍼는 공유되지 않는다.

---

### 6.2 로컬 버퍼의 책임

로컬 버퍼는 다음 역할을 가진다.

- 글로벌 SRAM에서 로드한 타일의 부분 적재
- 연산 중 임시 데이터 저장
- 레지스터 또는 파이프라인 연산 보조

로컬 버퍼의 데이터는
엔진 외부에서 관측되거나 재사용될 수 없다.

---

## 7. 메모리 계층 간 역할 비교 요약

아래는 각 계층의 역할을 요약한 것이다.

- DRAM
  - 영속 저장
  - 연산 파이프라인 외부

- 글로벌 SRAM
  - 타일 저장
  - 엔진 공유
  - 라이프사이클 기준

- STB
  - 타일 전달
  - 파이프라인 경계
  - 비저장 구조

- 로컬 버퍼
  - 엔진 내부 작업 공간
  - 비공유

---

## 8. 금지된 메모리 사용 패턴

다음 사용 패턴은 아키텍처적으로 금지된다.

- STB를 장기 데이터 저장소로 사용하는 행위
- 글로벌 SRAM을 캐시처럼 사용하는 행위
- 로컬 버퍼 데이터를 엔진 외부로 노출하는 행위
- 글로벌 SRAM 없이 STB만으로 타일을 전달하는 행위
- DRAM을 파이프라인 단계 사이에 삽입하는 행위

---

## 9. 시뮬레이터 구현에 대한 요구 사항

올바른 시뮬레이터는 다음을 만족해야 한다.

- 각 메모리 계층을 논리적으로 분리하여 모델링
- 글로벌 SRAM의 용량 제한 및 점유 상태 추적
- STB의 짧은 수명과 파이프라인 성격 반영
- 로컬 버퍼를 외부에서 접근 불가한 영역으로 취급

메모리 접근의 실제 지연 시간은 단순화될 수 있으나,
계층 간 **역할 혼합은 허용되지 않는다**.

---

## 10. 요약

- DRAM은 시작과 끝만 담당한다
- 글로벌 SRAM은 타일이 머무는 장소이다
- STB는 타일이 흐르는 통로이다
- 로컬 버퍼는 엔진 내부의 작업대이다

이 계층 구분이 유지되지 않으면,
타일 기반 아키텍처의 성능, 예측성, 확장성은 모두 붕괴된다.
